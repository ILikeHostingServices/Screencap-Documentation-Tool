How it works

The same three steps as Steps Recorder, with a full guide at the end instead of a zip of small pictures.

  1. Record

    Do the task as usual. Every click and key is noted. Typed text is never saved.

  2. Review

    Fix captions, reorder or remove steps, crop, and draw arrows or labels in the step editor.

  3. Export

    One click makes an HTML, Word, PDF, or PowerPoint document with your title, version, and logo.

What you get

A built-in recorder that notes every click

Each step gets a red ring where you clicked and a first-draft caption such as Click "Next". Recordings from Snipping Tool, OBS Studio, or any other recorder work too.

  • Optional narration becomes captions, transcribed offline
  • On Windows, the recorder window hides itself from the recording

Point readers at the right button

Draw arrows, numbered markers, and text labels. A red box shows what changed since the previous step, and a zoomed inset can show a small checkbox up close.

Sensitive text blurred for you

Passwords, license keys, tokens, and IP and email addresses are found with OCR and blurred. An unblurred copy is kept alongside in case you need the details. Shown here in the dark theme.

Finished documents, not just pictures

Export a single-file HTML guide, a Word document from your own template, a PDF, or a PowerPoint deck with one slide per step and narration in the speaker notes.

  • Alt text on every screenshot for screen readers
  • Your company logo on the title

Coming from Steps Recorder

Microsoft deprecated Steps Recorder (psr.exe) in 2023. It gets no more updates and is to be removed from Windows.

Installer Recommended

Download for Windows (x64) Download for Windows on ARM

Run the downloaded file. Setup asks whether to install for everyone on the PC or just you, offers to install FFmpeg if it is missing, and adds the screencap command to the PATH so it works in any terminal. After that, the app updates itself with Help > Check for Updates.

The installer is not code signed yet, so Windows may show Windows protected your PC. Choose More info, then Run anyway. To check the file first, compare it with SHA256SUMS.txt on the release page, as the code signing policy explains.

Snap Store Recommended

Get it from the Snap Store

Or install it from a terminal:

sudo snap install screencap-documentation-tool

Works on any distribution with snapd, on x86_64 and 64-bit ARM. FFmpeg, Tesseract OCR, and Pandoc are included, and updates install automatically.

apt and dnf repositories

Add the signed repository once, and the app updates with your normal system updates.

Ubuntu, Debian, Linux Mint, Pop!_OS, Raspberry Pi OS

sudo install -d /etc/apt/keyrings sudo curl -fsSLo /etc/apt/keyrings/ilhs-archive-keyring.gpg https://screencap.ilhs.app/ilhs-archive-keyring.gpg sudo curl -fsSLo /etc/apt/sources.list.d/screencap-docs.sources https://screencap.ilhs.app/apt/screencap-docs.sources sudo apt update sudo apt install screencap-documentation-tool

Fedora, RHEL, Rocky Linux, AlmaLinux

sudo curl -fsSLo /etc/yum.repos.d/screencap-docs.repo https://screencap.ilhs.app/rpm/screencap-docs.repo sudo dnf install screencap-documentation-tool

openSUSE

sudo zypper addrepo https://screencap.ilhs.app/rpm/screencap-docs.repo sudo zypper install screencap-documentation-tool

Packages and repository data are signed with the ILHS Package Signing key: ilhs-archive-key.asc. RHEL, Rocky Linux, and AlmaLinux also need EPEL and RPM Fusion for FFmpeg; see the note below.

macOS 11 or later · Apple silicon and Intel · Installed with Homebrew

Homebrew Recommended

  1. Install Homebrew if you do not have it yet. Paste this into Terminal and follow the prompts:

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

  2. Install the app:

    brew install ilikehostingservices/tap/screencap-documentation-tool

  3. Add it to Launchpad, Spotlight, and the Dock:

    ln -sf "$(brew --prefix)/opt/screencap-documentation-tool/ScreenCap Docs.app" ~/Applications/

  4. Optional: add automatic blurring and Word export:

    brew install tesseract pandoc

To update later, run brew upgrade screencap-documentation-tool. The first time you record, macOS asks you to allow Screen Recording and Input Monitoring; restart the app after allowing them.

Intel Macs work today. Homebrew plans to end support for Intel Macs in September 2027.

For IT and security teams

Nothing you record leaves the PC. The app runs as the signed-in user, has no service or background task, and goes online only to check for updates (administrators can turn this off) and to download the speech model once, if you use captions from narration.
